Code of Music — ML Examples

Front-end sketches live here. Some examples require a backend (FastAPI/Jupyter) running elsewhere and a public URL (ngrok or your own host).

MusicGen (sampler)

Generate one-shot samples from text prompts. Requires a MusicGen backend and an API URL.

Open MusicGen sketch

Spleeter (stem splitter)

Upload audio and split into stems. Requires a Spleeter backend and an API URL.

Open Spleeter sketch

Magenta RT — Holly (mic loop)

Hold to record, generate one chunk, then A/B morph raw ↔ model. Requires the Magenta RT backend + gateway URL.

Open Magenta RT sketch

Magenta RT — Holly (realtime)

Continuously stream Holly chunks while editing prompts, XY mix, params, and centroids. Uses ngrok bandwidth quickly.

Open Holly realtime sketch

Lyria Realtime (browser → Google)

Connects from your browser directly to Google’s realtime endpoint. Needs a Generative Language API key.

Open Lyria sketch
GitHub Pages note: Pages can host these static sketches, but it can’t run the Python backends. For backend-powered sketches, you’ll still need a backend host + public URL and paste it into the sketch UI.
